# 人体FBX / BVHの取り込み

上部の「FBX / BVH → 人体FBX / BVHの取り込み」を開きます。Kimodo NPZ専用の取り込みとは別の入口です。

1. FBXまたはBVHを選択。BVHは1単位あたりのm（cmなら0.01、mなら1）とY／Z上方向を指定して「読み込み・診断」。FBXはファイルの単位・軸設定からメートル／Z上方向へ変換します。
2. 元のボーン数・フレーム数・fpsを確認します。読み込み・変換は別スレッド、FBXのデコードは独立したネイティブ処理で行います。
3. SOMAの役割と元のボーンを対応付けます。MotionBuilder標準、名前空間付きMixamo、SOMA、UE系、VRM系の名前から候補を表示します。候補は必ず確認し、違うものをコンボボックスで修正してください。
4. 中立姿勢を確認します。「-1」はFBXのバインド姿勢／BVHのオフセット姿勢です。これがT姿勢でない場合やバインドがない場合は、**実際に中立T姿勢を記録したフレーム**を指定します。先頭の動作姿勢を自動で中立扱いにはしません。A姿勢や動作中の姿勢をT姿勢として設定すると、腕などの角度がずれます。任意の基準姿勢を自動推定する完成機能ではありません。
5. 必要なら正面の補正角を調整します。元の左右股関節とSOMAの左右股関節を基準に初期の正面を合わせ、追加のyaw補正を適用します。
6. 「確認用候補として取り込む」。ライブラリへ新しいmotionファイルとreviewファイルを保存します。完了後に「候補を読み込んで確認」を押し、動作編集で全尺を確認します。バックグラウンド変換の完了だけでは選択中のターゲットを置き換えません。プレビューボタンでの読み込みはUndoに対応します。既存ファイルは連番で避け、元ファイル・既存の採用済み動作は上書きしません。

ボーン対応表はJSONで保存・再読込できます。異なるボーン名一覧・単位／軸の設定には流用しません。中立姿勢のフレーム番号はテイクごとに確認してください。

## 対応範囲

- 人体型1体、1つのFBXアニメーションテイク。複数テイクは取り込み前に必要なものを分けて書き出します。
- 必須は腰・頭・左右上腕／前腕／手・大腿／すね／足、および背骨／胸の最低1関節。重複・存在しない対応や腕脚の親子不整合はエラーにします。
- 回転は基準姿勢で校正し、SOMAの骨長を保ちます。移動距離は左右の脚長比の平均で換算します。最初のルートXYを原点に移し、その後の移動・旋回を維持します。
- Studioの30fpsへ位置補間とクォータニオン補間で変換します。最終時刻が30fps境界に合わない場合は最後の元姿勢を端数区間で保持します。元fps・元尺・結果フレーム数をprovenanceへ保存します。
- 位置だけのIK解決、接地補正、平滑化、顔・布・髪・物理、任意のA／T姿勢間の自動解決は行いません。未対応のボーンはSOMA参照姿勢のローカル回転を保って親へ追従します。指の対応も確認してください。
- FBX SDKの独立した読み込みヘルパーを使うためBlenderは不要です。負／不均等なボーンスケールは誤変換を避けるため拒否します。対応表・基準姿勢の診断は、全モデルの接触やねじりの自然さを保証しません。

各ファイルは`review_candidate`として元パス・元SHA-256・対応表・軸・単位・fps・基準姿勢・倍率を保存。最終曲線のローカル／ワールド回転をreviewへ記録します。元素材の利用条件は引き続き適用されます。公開用データへ自動採用はしません。

## 検証

同じT基準の骨格で、31フレームの自作曲線をネイティブFBX書き出し→ネイティブ読み込み→SOMA変換し、ローカル／ワールド回転とルート変位を比較します。スキンのバインドA姿勢と骨格のT基準は区別します。提供モーキャプFBX（60fps／124ノード）と生成BVHも別の隔離領域で取り込み、保存・再読込と最終曲線ハッシュを確認します。確認候補の速度警告は残し、全尺目視・実メッシュ接触・UE適用・素材の利用条件の再確認を数値検査と区別します。
