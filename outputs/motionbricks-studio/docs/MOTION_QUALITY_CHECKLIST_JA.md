# モーション修正チェックシート

更新日: 2026-11-02。今後のダンス・歩行・走行・旋回・しゃがみ・障害物・座り立ち・手指の修正で使用する。

## 作業ごとの記録欄

|項目|記入内容|
|---|---|
|対象・版・担当|動作ID、修正前後の版、日付|
|参照元|動画/モーション名、元ファイルSHA-256、著作者、利用条件、改変内容|
|骨格と単位|ボーン名・階層・基準姿勢、XYZ軸、前方向、m/cm、ローカル/ワールド|
|時間|元fps、出力fps、総フレーム、尺、0始まりのフレーム番号と秒|
|修正対象|症状、ボーン、開始・終了フレーム、修正方法|
|保持するもの|修正対象外のフレーム・位置・接地・演技上のアクセント|
|検査証拠|最終曲線ハッシュ、計測JSON、比較動画、重点確認フレーム|
|判定|採用可能な改訂/検証候補/不採用、残件と次の対応|

チェック欄は「完了 / 未確認 / 問題あり / 対象外＋理由」で記入する。未確認を完了にしない。数値のしきい値は、その動作・fps・体格に対する検出目安であり、自然さや安定性の保証ではない。

## 1. 入力と変換

- [ ] 元データと利用条件を確認。参照・派生・独立制作を正しく区別した。
- [ ] 変換前に骨格階層、左右対応、基準姿勢、ボーン軸と単位を確認した。
- [ ] 頭、手首、足首の正面・上下・ねじり方向を基準姿勢で確認した。
- [ ] 24→30fpsなどの再サンプリングで尺・イベント時刻・最後のフレームがずれていない。
- [ ] 生成条件の連続4姿勢と、編集・再生・保存する全フレームの曲線を区別した。条件だけの確認を全動作の確認としていない。
- [ ] 遮蔽、関節の左右取り違え、縮んだ前腕、不正な顔検出を識別した。
- [ ] 欠落区間の補間と手作業補正を記録した。欠落を正面固定やゼロ角度で埋めて急変を作っていない。

## 2. 曲線と全身

- [ ] NaN/無限値、無効な回転、骨長・ローカルオフセットの変化がない。
- [ ] qと-qを同じ回転として扱い、短い経路で補間した。
- [ ] **ローカルと合成後ワールドの両方**で角速度・角加速度・最大箇所を検査した。
- [ ] 変化量をdeg/frameだけで判断せず、fpsとdeg/sも記録した。
- [ ] ルートの位置・速度・加速、腰・胸・肩・頭のつながり、開始・終了・ループ境界を確認した。
- [ ] クリップ接続は境界の1フレームだけでなく、前後の生成区間全体を検査した。短い補間で入口だけ滑らかになっても、後段の反転を見落としていない。
- [ ] 肘・膝の曲げ方向、手首・足首の軸回り、伸びきった関節での反転を確認した。
- [ ] 全身を平均化してタイミング・移動量・ポーズの強弱を失っていない。

## 3. 接触と重心

- [ ] 足の骨の高さに加え、足裏の表面、踵・爪先、浮き、滑り、接地切り替えを確認した。
- [ ] 足裏の最低点だけで接地合格にしていない。踵・前足部を別々に計測し、つま先だけが接地する意図しない姿勢を検出した。
- [ ] 支持脚・遊脚・踏み替えを参照と比較。重心の近似指標を物理的安定性の保証として扱っていない。
- [ ] 腕と胸・腹・頭、左右の腕・脚、手指の貫通を確認した。
- [ ] 「画面上は一致するが腕が背中側」という前後関係の誤りを確認した。
- [ ] 検査が楕円体・線分等の近似か、メッシュの実交差かを明記した。近似の警告を実貫通と断定しない。
- [ ] 指を握る/開く補正後も、指同士・掌・顔・胴体との接触を再検査した。

## 4. 動作別の追加欄

|動作|確認すること|
|---|---|
|歩行・走行・スキップ|左右の支持期間、接地/滞空、着地、歩幅、速度、ルートと足運び、ループの継ぎ目|
|旋回・横移動・しゃがみ|進行方向と向き、内外足、足の交差、頭の高さ、膝と股関節、速度変化|
|跳躍・乗り越え|助走、踏切、0.5/0.75mの高さと奥行き、全身のクリアランス、手の支持、着地と退出|
|くぐり抜け|入口/出口、頭・背中・腰の高さ、通過中の足運び、立ち戻り|
|座る・立つ|椅子位置/座面高、足の支持、尻と座面、重心移動、立ち上がりと退出|
|ダンス・手指|拍/アクセント、左右の腕と手、顔と視線、手指の独立時間軸、遮蔽、自己接触|

## 5. 最終曲線から再確認

- [ ] 最後の平滑化・IK・手指編集・接地補正後の曲線を計測し直した。
- [ ] 修正前後を同じカメラ・時刻・骨格・縮尺で並べた。
- [ ] 診断画像・動画が空や真っ黒になっていない。描画終了ログだけで検証済みとしない。
- [ ] 全尺を通常速度で確認し、問題箇所を低速・フレーム送りで確認した。
- [ ] 正面以外にも側面/斜め/背面を描画し、奥行きと貫通を確認した。
- [ ] 数値改善と見た目の改善を別々に記録した。テスト合格だけで公開品質としない。
- [ ] モーション保存/再読込で全フレーム・名前・参照元・尺が維持される。
- [ ] FBX/VMD等の書き出し後も軸・単位・ボーン・ルート・フレーム時刻を確認した。
- [ ] UE適用時は対象モデルの事前チェック、基準姿勢、リターゲット後の足首/手首/ルート/接地を確認した。
- [ ] 修正と無関係な項目を悪化させていない。悪化があれば候補として分離し、採用扱いにしていない。

## 今回の失敗から固定したルール

|起きたこと|原因・見落とし|次の作業で必ず行うこと|
|---|---|---|
|顔が別方向を向く|体用の推定を流用、アニメ顔の推定偏り、欠落時のゼロ埋め|顔を別確認、正面/横顔の基準確認、補正角度と欠落区間を記録|
|各骨は小変化なのに胸や首が急回転|親子の回転の合成を見ていない|ローカルとワールドの最大箇所を両方出す|
|平滑化で貫通が再発|関節を別々に平均化し、位置・接触・前後関係の相関を壊す|問題区間を限定し、補正後に同じ全項目で再評価|
|2D位置は合うのに腕が背中側|単眼の奥行きの不定性、前後の取り違え|参照で見えている腕の前後関係と側面描画を確認|
|足が跳ねる、別の足が浮く|支持フラグの急切替、骨高だけの補正、全身持ち上げ|足裏表面と支持切替を確認、ルート/両足を再評価|
|握り補正で別の貫通・角度跳び|指と掌の実形状を見ていない、左右だけ急に切替|左右独立に連続補間、手の表面と接触を再評価|
|よい計測値と実際の保存物が違う|計測後に編集、実験出力/古いレポートの混同|最終曲線のハッシュをレポートに保存し書き出し後照合|
|接続直後は滑らかでも数フレーム後に腕が反転|境界1フレームだけの判定、補間の短経路の切替|出口から次のターゲットまで全区間のローカル/ワールド回転を再検査し、悪化した補間は不採用にする|
|肩が凹む、肘が横に折れる|ボーンの軸と屈曲面を合わせず、回転速度だけを検査|左右のモデル軸を校正し、肘の屈曲面と肩のスキニング変形を別々に検査する|
|角度制限で反転や振付の遅れが発生|回転の枝切替、片方向の速度制限|制限領域の内側を通る補間、対称の時間処理、参照イベントの時刻を比較。接触を悪化させた版を一括採用しない|
|モーキャプ移植で伸びきり前後の膝が跳ぶ|ほぼ一直線の関節位置からIKポールを求めて符号が反転|元の大腿ボーンの基準軸から屈曲面を引き継ぐ。伸びきり近辺の回帰テストと、移植前後のローカル・ワールド角速度を確認する|
|重点確認画像が黒くなる|閉じたGLコンテキストの描画キャッシュを次のビューで再利用|ビューごとに独立したプロセスで描画し、空フレームをエラーにする|
|BVHを移植すると内腿が交差する|T姿勢の骨の向きだけを合わせ、長軸回りのねじりと膝の曲げ軸を校正していなかった|膝が十分に曲がった複数フレームから、元と移植先のローカルのヒンジ面を校正する。足幅変更で隠さず、接地処理後のワールド回転と実メッシュを再検査する|
|手足の位置は合うのに乗り越えで指・脛が物体へ入る|腰や関節点だけで障害物を判定し、手を置く前後と足先の厚みを検査していなかった|接触の前後を含む全尺で実際に変形した表面を検査する。離す際は手を先に持ち上げ、足裏・踵・爪先・膝・脛も確認する|
|同じ提供元なのに足首の傾き・腰高がずれる|別テイクの中立姿勢から脚長と足首の高さまで流用した。CMUの挿入T姿勢は実際の床より下にある場合もある|体格は実際の動作から測り、足の基準は同じテイクの静かな接地区間で校正する。姿勢の軸、体格、床原点を別々に扱う|
|IKの重みが0でも肩が変形する|同じ手の位置へ解き直す処理で、上腕の長軸回りのねじりまで変えていた|無効区間の元姿勢を維持し、必要なスイングだけを移す。手を固定した時だけでなく接触の前後と無効区間も再検査する|
|足裏は床より上なのに足が滑る|遊脚が床より下へ出た際、高さを床へ切り詰めたままXY移動を続けていた|接地フラグだけで判断せず、実際に床近くにある足のXY速度を確認する。遊脚の高さと着地の収束を明示し、元のタイミング・支持切替・接地を再確認する|
|交差の少ない参照に替えたら動作そのものがなくなる|FlickLegsのID等、スタイル名だけを見て立ち待機区間を脚のほぐし動作として選んだ|ラベルではなく、全尺の演技と対象部位の動きを確認する。通過、停止してしゃがむ、立ち待機、脚を上げる等を区別する|
|短い改訂クリップで高さ補正の時刻が合わない|以前の長いクリップの踏切時刻を固定値で流用した|実際の最終曲線に結び付く接地・滞空の重みを保存する。元より短いクリップを使う回帰テストも行う|
|接触だけ減るがねじりが急変する|接触数だけを最小化し、校正角の時間変化と参照との一致を確認しなかった|滑らかさ・角速度・関節の可動域・参照との違いを同時に確認する。高速な反転や参照を壊す候補は採用しない|

## 利用する検査

`app/studio_motion_review.py` の汎用検査で全フレームの回転・単位・骨長・ルートを記録する。画像合わせや接触の検査がある場合は同じレポートへ追加し、修正前後を比較する。目視・参照一致・UE確認等は自動合格にしない。
