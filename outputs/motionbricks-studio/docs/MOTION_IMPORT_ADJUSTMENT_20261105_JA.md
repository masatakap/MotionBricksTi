# 動作取り込みと使用範囲の検証

## 操作

1. モーション・ポーズライブラリの「動作を取り込む」から NPZ、FBX、BVH を選ぶ。FBX/BVH は「読み込み・診断」で骨格を確認し、「動作として調整」を開く。
2. 用途を選ぶ。「経路に沿って繰り返す移動」は開始側のターゲットから次の地点まで動作条件を維持する。「ターゲットで一度だけ再生」は使用範囲を到着後に再生する。「最初から最後まで必ず再生」は全尺を使う。「ポーズの目標として使う」は姿勢条件として使う。
3. 開始・終了フレームと、その場でのプレビューで内容を確認する。移動用では「歩行周期を提案」で姿勢・移動速度・利用できる接地情報から周期を選ぶ。範囲の調整後は再提案できる。経路上の曲がり方は登録後に実際のターゲットで生成して確認する。
4. 「ライブラリへ登録」で独立した候補を保存する。同名の場合は番号が付く。全フレームと用途・使用範囲を保存し、元の素材ファイルは保持する。
5. 通過用では登録した候補を「環境 → 環境・障害物 → 自作の動作設定を読み込む」でボックスに指定し、ジャンプまたはくぐりを選ぶ。前進距離とボックスに対するスキン頂点の干渉を調べる。通過後も移動する設定では、全身が通過して接地し、前進している安全な退出フレームを選べた場合に終盤を省く。安全な退出候補を検出できない場合は指定範囲を使う。
